# Lucky Claw

Fullscreen arcade claw parlor with **multiple machines**, fair skill grabs, and openable prizes (toys, phones, watches, and more).

## Machines

| Machine | Cost | Difficulty | Prizes |
| --- | --- | --- | --- |
| Toy Box | 2c | normal | ducks, bears, cars, stars |
| Plush Palace | 4c | hard | dolls, bots, plush |
| Gadget Grab | 7c | expert | phones, watches, headphones |
| VIP Vault | 12c | legend | tablets, gold, premium tech |

Harder machines have tighter grab pockets and more claw sway — but if you land on a prize, you still keep it.

## Run

```bash
npm install
npm run dev
```

## Controls

- `1`–`4` switch machines
- `←` `→` aim
- `Space` drop / play
- **BAG** opens sealed prizes for coins
