# Lucky Claw

Fullscreen arcade claw parlor with **20 levels**, fair skill grabs, and openable prizes (toys, phones, watches, and more).

## Run

```bash
npm install
npm run dev
```

## Controls

- `1`–`9` / `0` quick-pick levels 1–10
- `[` `]` cycle all 20 levels
- `←` `→` aim · `Space` drop/play
- **BAG** opens sealed prizes for coins
