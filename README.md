# Lucky Claw

Arcade claw-machine game in the browser. Aim the claw, grab a prize, then **open** sealed capsules for coins and collectibles.

## Fair play (not a scam claw)

- If the claw lands on a prize, **you keep it**. Always.
- No hidden fail chance and no mid-lift random slips.
- Misses only happen when you miss the prize with your aim.

## Play loop

1. Insert a coin and move the claw.
2. Drop onto a plush / orb.
3. Won prizes go into your **Prize Bag** as sealed capsules.
4. Open capsules for coins, score, and stickers — every open pays out.
5. Use coins from opens to keep playing.

## Run

```bash
npm install
npm run dev
```

## Controls

| Input | Action |
| --- | --- |
| `←` `→` / `A` `D` | Move claw |
| `Space` / `Enter` | Drop or start round |
| On-screen buttons | Same on touch |
| Prize Bag → OPEN | Crack a sealed capsule |
