# Lucky Claw

Fullscreen arcade claw parlor with **10 levels**, fair skill grabs, and openable prizes (toys, phones, watches, and more).

## Levels

| Lvl | Machine | Cost | Unlock | Focus |
| --- | --- | --- | --- | --- |
| 1 | Toy Box | 2c | start | toys |
| 2 | Candy Corner | 3c | 2 wins | sweets |
| 3 | Plush Palace | 4c | 4 wins | dolls |
| 4 | Race Track | 5c | 6 wins | cars |
| 5 | Bot Bay | 6c | 9 wins | robots |
| 6 | Gadget Grab | 8c | 12 wins | phones/watches |
| 7 | Chrono Hall | 10c | 16 wins | watches |
| 8 | VIP Vault | 14c | 20 wins | tablets |
| 9 | Fortune Forge | 18c | 26 wins | gold |
| 10 | Mythic Machine | 25c | 35 wins | final boss |

Higher levels = tighter grab pocket + more claw sway. Still fair: land on it, keep it.

## Run

```bash
npm install
npm run dev
```

## Controls

- `1`–`9` / `0` pick levels 1–10
- `[` `]` cycle levels
- `←` `→` aim · `Space` drop/play
- **BAG** opens sealed prizes for coins
